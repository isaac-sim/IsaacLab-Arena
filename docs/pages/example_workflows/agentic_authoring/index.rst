Agentic Authoring
=================

Explore using coding agents to turn task descriptions into reviewable Arena
environments. See the `author-environment skill
<https://github.com/isaac-sim/IsaacLab-Arena/blob/main/skills/developer/author-environment/SKILL.md>`_
and :doc:`Arena's agentic tools <../../agentic_tools/index>`.

* :doc:`workbench` covers preparing assets, viewing an existing agent-authored
  environment, prompting Codex to author a new task, and running a force-based
  reference demonstration.
