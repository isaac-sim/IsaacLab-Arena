Running your First Experiments
==============================

The previous page made explicit environment choices one at a time. First, collect those choices in
an Arena Experiment and execute its named Runs from one YAML file. Next, use Arena's variation
system to sample controlled changes automatically. You will then evaluate a real pre-trained
policy in closed loop.
